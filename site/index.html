Approach

Learned perception, explainable rules

One camera, one intersection, unknown test videos from the same mount. The pipeline decodes every 3rd frame, aligns each recording onto a reference frame, tracks road users, and turns trajectories plus hand-measured scene geometry into events. Learned models do the perception; rules do the reasoning, so every event can be explained.

ComponentHow
Detection & trackingLearned: YOLO11n (COCO) + BoT-SORT
Camera alignmentClassical: ORB features, RANSAC similarity, every 10 s
Metric calibrationFitted pinhole camera (pedestrian heights, lane vanishing point, 14 m stop line)
Traffic-light colourClassical: HSV + lamp position
14 event classesRules on trajectories, geometry and light state
Accident / near-miss / obstacleLearned: Qwen3-VL-2B verifier, P(yes) from next-token logits
Accident risk (Part B)Physics: time-to-collision and required deceleration between tracks

Report

What worked, what did not, what is next

What worked

  • Checking every rule on real frames, not only on synthetic tests: it caught the pedestrian-vs-vehicle signal mix-up, riders counted as pedestrians, people waiting on the kerb, and red-to-green line creeping.
  • Traffic-light state from an absolute lit-pixel count plus lamp position: clean ~33 s red / ~36 s green cycles on all four videos, day and dusk.
  • Runtime alignment: the same geometry lands on the zebras in every recording.
  • Metric calibration from pedestrian heights: two independent scale cues agree within 3 %.
  • A Qwen3-VL-2B verifier answering yes/no from logits: 0 of 98 false accident / near-miss / obstacle candidates accepted.
  • 1.6–1.7× video duration for Part A + B on an Apple M4, inside the 3× limit.

What did not (yet)

  • No ground truth: thresholds are tuned by eye, so precision and recall are not measured.
  • The VLM verifier's recall is untested: the samples contain no accident. Fire/smoke stays disabled.
  • The tracker switches IDs at 10 fps, which shortens trajectories.
  • Not yet timed on the evaluation GPU (T4).
  • Part B is a physics baseline without accident examples to calibrate on.

Next

  • Annotate the sample videos and tune thresholds against evaluate.py.
  • Model the far-road approach (stop line, signal from traffic flow).
